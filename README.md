World's most insane prompt generator for Suno, Udio, Riffusion, and beyond. Generate **4 octillion** unique music prompts with one click. From "Rap Metal-Polka in a Tibetan Steampunk Airship" to "Yodeling Ghost Opera in a Neon Jungle" – chaos guaranteed.

## Features
- **Random Mode**: Pure insanity – mixes genres, moods, instruments, cultures, and more.
- **Manual Mode**: Surgical control over themes, vocals, BPM, narratives.
- **GUI Built with Tkinter**: Easy drag-and-drop interface, no coding needed.
- **Export**: Copy to clipboard or save to .txt for direct Suno/Udio paste.
- **Infinite Variety**: 378 genres, 115 moods, 69 instruments... you get it.

## Installation
1. Clone the repo: `git clone https://github.com/tomknot80/suno-chaos.git`
2. Install dependencies: `pip install tkinter` (usually pre-installed).
3. Run: `promtmachine2000.py` (or whatever you named the file).
4. Click "Generate Prompt" and watch the magic.
